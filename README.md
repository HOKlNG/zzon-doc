## 소개

**zzon-doc**은 Claude Code에 문서화 스킬 4종을 더해 주는 플러그인입니다. 코드베이스를 분석해 다이어그램과 문서를 저작하고, 서버·라이브러리·CDN 없이 브라우저에서 바로 열리는 **self-contained 단일 `.html`**로 렌더링합니다.

| 스킬 | 하는 일 |
|---|---|
| **zzon-doc** | 다이어그램 메인 스킬입니다. 코드에서 센 사실로 **무엇을(뷰 13종) 얼마나 복잡하게(등급 3단)** 그릴지 정하고, 품질 게이트를 통과한 그림만 내놓습니다. 코드가 바뀌면 낡은 그림을 짚어 갱신합니다 |
| **zzon-seq** | 기능의 코드 경로를 추적해 액터 간 요청/응답 왕복을 시간축 시퀀스로 그립니다 |
| **terra-form** | Terraform(`*.tf`)을 읽어 클라우드 인프라를 AWS 공식 아이콘으로 그립니다 |
| **zzon-wiki** | 프로젝트 개발 문서 위키를 만들고, 코드 스캔과 질문으로 내용을 채웁니다 |

## 주요 기능

- **13종 뷰** — 컨텍스트 · 컨테이너 · 컴포넌트 · 배포/인프라 · 데이터 흐름 · ERD · **상태 전이도 · 플로우차트 · 모듈 의존성 · 화면 흐름 · 도메인 모델(클래스)** · 에이전트 구조 · 시퀀스를 지원합니다.
- **객관적인 선택 기준** — 코드에서 센 사실(테이블 · 라우트 · IaC 리소스 · 상태 enum · 화면 · 모듈 수)과 요청어로 그릴 뷰를 고르고, 독자와 매체에 맞춰 **개괄(≤9) · 표준(≤20) · 원장(≤50)** 등급을 정합니다. 넘치면 정해진 순서로 줄이고, 줄인 내용을 보고합니다.
- **품질 게이트** — 겹침 · 관통뿐 아니라 교차 · 라벨 가림 · 꺾임 · 색 수 · 흐름 방향, 그리고 상태도 도달성이나 플로우차트 분기 라벨 같은 **표기 의미**까지 검사합니다.
- **갱신 누락 방지** — 장마다 근거 파일의 해시를 기록해 두고, 코드가 바뀐 뒤 "다시 훑어줘"라고 하면 어떤 그림이 어떤 파일 때문에 낡았는지 짚어 줍니다.
- **모듈 의존성 기계 추출** — import 문을 읽어 모듈 그래프를 생성합니다(JS/TS · Python · Go · Java/Kotlin). 순환은 빨간색으로 표시합니다.
- **큰 그림과 세부 판단** — 노드 수와 독자에 따라 한 장으로 그릴지, 큰 그림을 함께 그릴지 정합니다. 큰 그림은 세부 모델을 접어 만들고 드릴다운으로 이어집니다.
- **선이 겹치지 않는 캔버스** — 선끼리 포개지거나 라벨이 가리면 간격을 넓혀 다시 배치하고 가장 깨끗한 결과를 씁니다. 깨끗한 그림은 원래 크기를 유지합니다. 작성용 배치 가이드도 함께 제공합니다.
- **하나의 디자인 · 반응형** — 통합 문서, 위키, 다이어그램 뷰어, 시퀀스 뷰어가 같은 색 · 글꼴(Pretendard) · 컨트롤을 씁니다. 휴대폰에서는 메뉴가 서랍이 되고, 상세는 아래 시트로 열리며, 두 손가락으로 확대할 수 있습니다.
- **의존성 0 출력** — 라이브러리 · CDN 없이 self-contained 단일 `.html`을 만듭니다.
- **인터랙티브 뷰어** — 노드 클릭, 플로우 강조, 순번 배지, 드릴다운(⊕ 더블클릭), 호버 툴팁, 팬/줌, 다크 모드, SVG/PNG 내보내기(순수 벡터)를 지원합니다.
- **통합 문서** — 여러 장을 좌측 메뉴와 전체보기로 묶어 하나의 문서 사이트로 만듭니다.
- **시퀀스 다이어그램** — 전체/간소화 토글, 단계 상세(근거 코드 위치), 둘러보기(단계 재생), alt/opt/loop/par 분기를 지원합니다.
- **Terraform 인프라** — AWS 공식 아이콘 838종, Azure 공식 아이콘 636종, 쿠버네티스 39종, SAP BTP 125종을 내장했습니다. 재배포가 허락되지 않은 클라우드(GCP 등)는 카테고리 카드로 그립니다. 아이콘을 따로 내려받을 필요가 없습니다.
- **문서 위키** — 진행 현황과 열린 질문을 추적하는 위키 사이트를 생성하고, 아키텍처 문서에 다이어그램을 임베드합니다.
- **범위 제안** — 큰 프로젝트는 구조를 먼저 파악해 몇 장을 어느 깊이로 그릴지 제안합니다.
- **로컬 분석** — 코드는 로컬에서만 분석합니다. 네트워크 요청과 텔레메트리가 없습니다.

## 시작하기

### 요구 사항

- Claude Code (플러그인/스킬 지원 버전)
- Node.js 20+ — 빌드 스크립트 실행에 필요합니다
- [bun](https://bun.sh) — 다이어그램 엔진 실행에 필요합니다. **새로 그리는 구조 · 인프라 다이어그램과 terra-form은 bun이 필수**이며, 없으면 레거시 DiagramSpec JSON 렌더 · 시퀀스 · 위키만 동작합니다(자동 폴백)

### 설치

```
/plugin marketplace add HOKlNG/zzon-doc
/plugin install zzon-doc@zzon
```

다이어그램 엔진은 최초 1회 준비가 필요합니다.

```bash
cd zzon-doc/engine && bun install
```

## 사용법

`/zzon-doc:zzon-doc <요청>`으로 부르거나, 자연어로 요청하면 자동으로 동작합니다. (플러그인 스킬은 `플러그인명:스킬명` 네임스페이스를 씁니다.)

**① 프로젝트 전체 아키텍처** — 구조를 먼저 파악해 **무엇을 몇 장으로 그릴지 제안**하고, 합의하면 여러 문서로 만들어 통합 뷰(좌측 메뉴 + 전체보기)로 묶어 줍니다.

```
/zzon-doc:zzon-doc 이 프로젝트의 아키텍처 그려줘
```

**② 특정 부분만** — 원하는 한 부분을 한 장으로 그립니다.

```
/zzon-doc:zzon-doc 이 repo의 클라우드 아키텍처 그려줘
```

**③ 기능 시퀀스 다이어그램** — 특정 기능의 코드 경로(라우트→서비스→큐→워커)를 추적해 시간축 시퀀스로 그립니다.

```
/zzon-doc:zzon-seq 결제 흐름 시퀀스 다이어그램 그려줘
```

**④ Terraform 인프라** — `*.tf`를 읽어 클라우드 인프라를 그립니다. AWS · Azure는 공식 아이콘으로, 쿠버네티스 · SAP도 전용 아이콘으로 그리고, 나머지 클라우드는 카테고리 카드로 표현합니다.

```
/zzon-doc:terra-form ./infra
```

**⑤ 상태도 · 플로우차트 · 의존성** — 지명하면 그 뷰로, 지명하지 않으면 선택 기준이 판단합니다.

```
/zzon-doc:zzon-doc 주문 상태 전이도 그려줘
/zzon-doc:zzon-doc 환불 정책을 플로우차트로 그려줘
/zzon-doc:zzon-doc 모듈 의존성 그래프 그려줘
```

**⑥ 코드가 바뀐 뒤 갱신** — 근거 파일 해시로 낡은 그림을 먼저 짚고, 바뀐 파일만 다시 읽어 고칩니다.

```
/zzon-doc:zzon-doc 코드 많이 바뀌었는데 다이어그램 최신화해줘
```

**⑦ 프로젝트 문서 위키** — 티어(라이트/표준/풀)를 합의한 뒤, 코드에서 읽히는 내용은 자동으로 쓰고 모르는 내용은 질문으로 채웁니다. 이미 만든 위키는 빠진 내용과 사람이 고친 문서를 감지해 이어서 채웁니다.

```
/zzon-doc:zzon-wiki 이 프로젝트 문서 위키 만들어줘
```

생성된 `.html`은 **노드 클릭 · 플로우 강조 · 순번 배지 · 호버 툴팁 · 팬/줌 · 다크 모드**가 되는 인터랙티브 문서입니다.

### 산출물 위치

산출물(스펙 · 다이어그램 · 위키 상태)은 대상 프로젝트의 **`docs/zzon-doc/`** 아래에 생성됩니다. 이전 버전 기본값인 루트 `zzon-doc/` 폴더가 이미 있으면 그대로 이어서 사용합니다.

## 직접 렌더링 (선택)

스킬 없이 손으로 만든 스펙도 렌더링할 수 있습니다.

```bash
# 단일 .html 한 장
node zzon-doc/skills/zzon-doc/scripts/render.mjs <spec.json> [-o out.html]

# 여러 스펙 → 통합 문서 (docs/zzon-doc/specs/*.json → docs/zzon-doc/index.html)
node zzon-doc/skills/zzon-doc/scripts/build-docs.mjs ./docs/zzon-doc --title "문서 제목"

# 근거 대조 — 어떤 그림이 코드 변경으로 낡았는지 (쓰기 없음)
node zzon-doc/skills/zzon-doc/scripts/build-docs.mjs ./docs/zzon-doc --status

# 코드 사실 스캔 · 모듈 의존성 생성 · 품질 게이트
node zzon-doc/skills/zzon-doc/scripts/scan.mjs <프로젝트>
node zzon-doc/skills/zzon-doc/scripts/scan-deps.mjs <프로젝트> --out ./docs/zzon-doc/terra/deps.ts
cd zzon-doc/engine && bun ia check ../../docs/zzon-doc/terra/deps.ts
```

빌드 스크립트는 Node 20+ 내장 모듈만 사용합니다. 구조 다이어그램의 렌더러는 내장 엔진(bun)이고, bun이 없으면 **레거시 DiagramSpec JSON에 한해** 레거시 렌더러로 자동 폴백됩니다. 어느 쪽이든 출력 `.html`은 외부 요청 0의 self-contained입니다.

## 최근 변경 사항

- **v0.9.1 — AWS 기술 블로그 문체 · 문체 검사 · 화면 맞춤 개선** : 생성 문서의 말투를 AWS 기술 블로그 기준으로 다시 정했습니다. 본문은 합니다체로 쓰고, 개요부터 관련 자료까지 정해진 문서 틀을 따릅니다. 결정 번호나 티켓 번호는 본문에 쓰지 않고 마지막 관련 자료 절에 이름 붙은 링크로만 둡니다. 품질 검사와 위키 상태 검사가 제목·라벨·본문에 남은 추적 코드와 줄표를 세어 알려 줍니다. 처음 화면에 맞출 때 범례와 플로우 버튼이 그림을 가리지 않고, 간격 재배치가 그림을 지나치게 넓히지 않으며, ERD 머리글의 컬럼 개수 표시를 없앴습니다. 격자 배치 그림의 큰 그림 판단 오류도 고쳤습니다. 큰 그림은 같은 두 노드 사이 선을 하나로 합치고 지름길 선을 빼서 선 한도를 지키며, 위키는 큰 그림이 있는 그림을 넣으면 큰 그림을 먼저 보여 줍니다. 세로로 긴 플로우차트는 처음 열 때 읽을 수 있는 크기로 위쪽부터 보여 주고, PNG 내보내기에서 글자가 중간에 잘리던 문제를 고쳤습니다. AWS 한국어 블로그와 같은 잣대로 문장 길이, 목록, 표, 백틱, 가운뎃점 밀도를 재는 "글의 결" 기준을 더해, 합니다체로만 바꾼 단문 나열이 아니라 이어진 줄글로 쓰게 합니다.
- **v0.9.0 — 다이어그램 메인 · 객관 선택 기준 · 표기 뷰 5종** : zzon-doc이 다이어그램 요청 전반을 받는 메인 스킬이 되었습니다. 코드 사실 스캔과 선택 기준표로 뷰와 등급을 정하고, 품질 게이트(가독성 지표 + 표기 의미 검사)를 통과시킵니다. **상태 전이도 · 플로우차트 · 모듈 의존성 · 화면 흐름 · 도메인 모델**을 새로 그립니다. 장마다 근거 파일을 기록해 코드가 바뀐 뒤 낡은 그림을 짚어 줍니다. 엔진 배치도 크게 개선했습니다(작성자 열 구조 힌트, 레거시 lane 복원, 같은 열 C자 우회, 라벨이 다른 선을 피함, 글줄식 줄바꿈). Windows에서 엔진이 멈추던 문제도 고쳤습니다. 이어서 모든 화면의 디자인을 하나의 토큰으로 통일하고 390 · 768 · 1440 폭에서 반응형으로 다듬었습니다. 상태 전이도 · 플로우차트 · 모듈 의존성은 아키텍처와 같은 카드로 그리고, 큰 그림 · 세부 판단과 자동 접기, 선 겹침 측정과 간격 재배치, Azure · 쿠버네티스 · SAP 아이콘, 독자용 문체 규칙을 더했습니다.
- **v0.8.3 — 뷰어 버그픽스 · 저작 정책** : 노드를 클릭해도 상세 사이드바가 열리지 않던 버그(포인터 캡처가 클릭을 svg 루트로 리타깃)와 플로우 해제 후 강조 잔상이 남던 버그를 수정했습니다. 저작 정책도 교정했습니다 — 설명 문장은 캔버스가 아니라 노드 `description`(우측 사이드바)에 담고, 구조 장에도 대표 플로우 1~2개를 기본 포함합니다.
- **v0.8.2 — 어휘 정책 · 시퀀스 슬롯 · 플로우 품질** : terra-form이 클라우드 전반(IaC 기반)으로 확장되었습니다. 레거시 DiagramSpec에 `"vocabulary": "aws"` 한 줄로 클라우드 아이콘 어휘를 선택할 수 있고(혼용은 validator가 차단합니다), zzon-wiki 카탈로그에 핵심 프로세스 시퀀스(seq-flows) 슬롯이 생겨 제안 단계에서 시퀀스가 자동으로 올라옵니다. 밀집 플로우의 엣지 라벨(통로 폭 적응 · 카드 위 pill 렌더)과 스텝 포커스 강조도 개선했습니다.
- **v0.8.1 — 통합 다이어그램 엔진** : 구조 · 데이터 다이어그램(infra/data-flow/erd/agent-topology)이 **내장 TS 엔진**으로 렌더됩니다. 진짜 자동 배치(ELK), 직교 라우팅, 겹침 · 관통 불변식을 갖췄고, 뷰어는 기존 UX(사이드바 · 플로우 · 범례 · 테마)를 그대로 유지합니다. 기존 DiagramSpec JSON은 변환이 내장돼 그대로 렌더되며, 레거시 렌더러는 `ZZON_LEGACY_RENDER=1` 또는 스펙의 `"renderer":"legacy"`로 사용할 수 있습니다.

## 이름에 대하여

`zzon-doc`은 제가 좋아하는 고양이 **쫀떡(zzon-ddeok)**이의 이름에서 왔습니다. 유튜브 채널 [김쫀떡](https://www.youtube.com/@김쫀떡)의 바로 그 쫀떡이입니다. 문서와 다이어그램(**doc**)을 다루는 도구라, `zzon-ddeok`을 언어유희로 비틀어 **`zzon-doc`**이 되었습니다. 🐱
