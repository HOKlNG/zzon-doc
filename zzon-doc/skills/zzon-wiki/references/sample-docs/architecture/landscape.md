## 읽는 법

- 요청은 왼쪽에서 오른쪽으로 흐른다. CDN과 웹 방화벽을 지나 게이트웨이에 닿고, 도메인 서비스가 처리해 저장소에 기록한다.
- 주문, 상품, 회원, 검색 도메인은 각자 서비스와 그 서비스의 DB를 위아래로 둔다. 도메인끼리는 서로 직접 호출하지 않는다.
- 큐와 워커가 맡는 비동기 처리, 그리고 이벤트 스트림에서 웨어하우스로 이어지는 데이터 플랫폼은 오른쪽 열에 따로 있다.
- 시크릿 관리, 배포, 관측처럼 모든 도메인에 걸친 운영 기능은 아래쪽 띠에 모았다.
