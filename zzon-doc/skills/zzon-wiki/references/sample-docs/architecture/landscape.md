## 읽는 법

- **좌→우가 요청의 흐름**이다: 사용자 → 엣지(CDN·WAF) → 게이트웨이 → 도메인 → 데이터.
- **도메인 밴드**(주문/상품/회원/검색)는 각자 서비스→DB 수직 스택이다. 도메인 간 직접 호출은 없다.
- 비동기(큐·워커)와 데이터 플랫폼(스트림→웨어하우스)은 오른쪽 별도 열이다.
- 운영·보안 띠(시크릿·배포·관측)는 하단 횡단 관심사다.
