## 개요

데모숍은 상품 전시부터 주문, 결제, 알림까지 맡는 커머스 플랫폼입니다. 이 문서는 누가 데모숍을 쓰고 데모숍이 어떤 외부 시스템과 통신하는지 정리합니다. 데모숍 내부의 서비스와 저장소는 다루지 않습니다.

## 아키텍처

그림 1은 데모숍을 둘러싼 사용자와 외부 시스템입니다. 데모숍을 더블클릭하면 내부 구성 그림으로 넘어갑니다.

### 사용자

구매자는 웹이나 모바일 앱에서 상품을 찾아보고 주문하고 결제합니다. 운영자는 상품과 재고, 주문을 관리하는 내부 직원입니다.

### 외부 시스템

| 시스템 | 용도 | 연동 방식 |
|---|---|---|
| 토스페이먼츠 | 결제 승인과 취소 | REST API, 동기 호출 |
| 메일 서비스 (SES) | 주문 확인 메일과 알림 메일 | REST API, 동기 호출 |
| 물류 시스템 | 출고 지시와 배송 추적 | 이벤트, 비동기 |

> ❓ 미확인(q-001): 결제대행사는 토스페이먼츠 한 곳만 쓰는가, 여러 곳을 연동할 예정인가?

## 경계 원칙

데모숍은 결제 수단 정보를 저장하지 않습니다. 결제대행사가 발급한 토큰만 보관합니다.

물류 시스템에는 이벤트를 보내기만 하고 응답을 기다리지 않습니다. 배송 상태는 물류 시스템이 웹훅으로 알려 줍니다.
