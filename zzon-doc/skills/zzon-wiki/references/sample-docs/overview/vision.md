## 개요

데모숍은 소상공인이 개발자 없이도 자기 브랜드의 스토어를 열 수 있게 하는 커머스 플랫폼입니다. 이 문서는 데모숍이 푸는 문제와 지향점, 첫 분기 성공 기준을 정리합니다.

## 배경

오픈마켓에 입점하면 수수료 부담이 크고 브랜드를 드러내기 어렵습니다. 데모숍은 운영이 쉬운 독립 스토어를 지향합니다.

## 목표

스토어를 열고 첫 판매를 하기까지 하루 안에 끝내는 것이 첫째 목표입니다. 결제와 물류는 검증된 외부 서비스에 맡기고 직접 만들지 않습니다. 운영자는 개발자 도움 없이 상품과 주문, 정산을 처리할 수 있어야 합니다.

첫 분기 성공 기준은 활성 스토어 50곳과 주문 성공률 99% 이상입니다.
