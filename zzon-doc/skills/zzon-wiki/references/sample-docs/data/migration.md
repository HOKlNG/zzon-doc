## 도구와 흐름

스키마 변경은 Prisma Migrate로 관리한다. 마이그레이션 파일은 PR에 함께 올려 코드와 같이 리뷰한다.

```bash
pnpm db:migrate:dev     # 로컬: 스키마를 바꾸고 마이그레이션 파일을 만든다
pnpm db:migrate:deploy  # 배포 환경: 있는 파일을 적용만 하고 새로 만들지 않는다
```

## 규칙

- 컬럼 삭제나 타입 축소처럼 되돌리기 어려운 변경은 두 번에 나눠 배포한다. 먼저 그 컬럼에 쓰지 않게 배포하고, 다음 릴리스에서 컬럼을 지운다.
- 이미 만든 마이그레이션 파일은 고치지 않는다. 잘못됐으면 되돌리는 마이그레이션을 새로 만든다.
- 대량으로 데이터를 채우는 작업은 마이그레이션이 아니라 별도 스크립트로 돌려서 배포 시간과 떼어 놓는다.
