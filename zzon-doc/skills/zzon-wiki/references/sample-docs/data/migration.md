## 도구와 흐름

스키마 변경은 Prisma Migrate로 관리한다. 마이그레이션 파일은 PR에 포함되어 코드와 함께 리뷰된다.

```bash
pnpm db:migrate:dev     # 로컬 — 스키마 변경 + 마이그레이션 파일 생성
pnpm db:migrate:deploy  # 배포 환경 — 파일 적용만 (생성 금지)
```

## 규칙

- **파괴적 변경(컬럼 삭제·타입 축소)은 2단계로** — 먼저 쓰기 중단 배포, 다음 릴리스에서 제거.
- 마이그레이션 파일은 수정하지 않는다 — 잘못됐으면 새 마이그레이션으로 되돌린다.
- 대량 백필은 마이그레이션이 아니라 별도 스크립트로 — 배포 시간과 분리한다.
